# 🌐 Hub Inclusivo

O **Hub Inclusivo** é uma plataforma web que apresenta informações sobre **gamificação na educação** e como elementos presentes nos jogos podem ser utilizados para tornar o aprendizado mais **interativo, motivador e inclusivo**.

## 🎯 Objetivo

O projeto tem como objetivo apresentar o conceito de **gamificação**, seus benefícios e suas aplicações no ambiente educacional.

A proposta é mostrar como mecânicas de jogos, como **desafios, recompensas, níveis e conquistas**, podem contribuir para uma experiência de aprendizagem mais dinâmica e envolvente.

## ✨ Seções

- 🏠 **Início** — Apresentação do projeto e introdução à gamificação.
- 🔬 **Ciência por Trás** — Explicação sobre os conceitos e fundamentos por trás da gamificação.
- 🕐 **Linha do Tempo** — Evolução e principais acontecimentos relacionados à gamificação.
- 🎮 **Banco de Recursos** — Recursos e exemplos que podem ser utilizados para aplicar a gamificação na educação.

## 🛠️ Tecnologias

- **HTML5** — Estrutura e organização do conteúdo.
- **CSS3** — Estilização, identidade visual e responsividade.
- **Figma** — Prototipação e planejamento da interface.

## 🎨 Design

O design do **Hub Inclusivo** foi desenvolvido no **Figma**, buscando criar uma interface **moderna, interativa e intuitiva**, utilizando elementos visuais inspirados no universo dos jogos.
